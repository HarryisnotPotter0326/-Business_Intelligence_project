# 第六章　RQ2 延伸：資料量與大型語言模型

## 6.1　學習曲線

表 6-1 為不同訓練資料量下各方法的測試 AUC，有三點發現：

（1）**資料越少，預訓練模型的優勢越大**。只有 1,000 筆時，BERTimbau Large 凍結比 TF-IDF 高 1.78 個百分點；用全部資料時只高 0.85 個百分點。BERTimbau Base 微調只用 5,000 筆（97.99%），就勝過 TF-IDF 用全部 30,464 筆（97.42%）。

（2）**LLM 的資料效率最高**。Qwen2.5-1.5B 以 LoRA 微調時，1,000 筆就達到 98.08%，與 Base 微調用 10,000 筆的水準相當；全部資料時達到 98.70%。Qwen2.5-3B 調整學習率後為 98.72%，與 1.5B 相當，模型放大沒有再提高準確度。

（3）**延長訓練沒有幫助**。第二輪把小資料點的 Base 微調延長到 8 個 epoch、Qwen-1.5B 延長到 3 個 epoch，並依驗證集選 epoch，結果都沒有變好；繼續訓練時訓練損失下降、測試 AUC 卻變差，是典型的過度配適。因此上述結論不是訓練長度不足造成的。

> TABLE 表 6-1　不同訓練資料量的測試 AUC（%）
| 訓練筆數 | TF-IDF | Large 凍結 | Base 微調 | Qwen-1.5B LoRA | Qwen-3B LoRA |
|:---|:---:|:---:|:---:|:---:|:---:|
| 1,000 | 95.64 | 97.42 | 97.35 | **98.08** | 98.02 |
| 5,000 | 96.81 | 97.91 | 97.99 | **98.46** | 98.44 |
| 10,000 | 97.09 | 98.02 | 98.13 | **98.44**† | — |
| 30,464 | 97.42 | 98.27 | 98.34 | 98.70 | **98.72** |
> NOTE 註：1,000–10,000 筆為 3 個種子的平均；全部資料時 TF-IDF 與凍結模型只跑 1 次。Base 微調訓練 3 個 epoch，依驗證集選 epoch。Qwen-3B 為第二輪調整學習率（1e-4）後的結果，全部資料為 3 個種子，1,000 與 5,000 筆各 1 個種子。† 第二輪補做。

## 6.2　大型語言模型

表 6-2 比較三種規模的 Qwen2.5。**零樣本與少樣本提示**不需要訓練資料：1.5B 零樣本的 AUC 為 97.01%，接近 TF-IDF 用 3 萬筆訓練的 97.38%，但低於所有 BERTimbau 方法；模型越大也不一定越好（3B 為 96.86%）。在提示中加入 8 則範例只提高 0.2–0.4 個百分點，推論時間卻變成 6–60 倍。另外，提示式用法會把太多評論判成負面（判為正面的只有 57%–64%，實際為 70%），在驗證集上調整判斷門檻後，準確率可提高 0.9–4.0 個百分點，因此零樣本 LLM 上線前一定要用少量標註資料校正門檻。

**LoRA 微調**才能讓 LLM 追上 BERT：1.5B 為 98.70%，與 BERTimbau Large 微調的 98.60% 相當。3B 第一次沿用 1.5B 的學習率 2e-4，只有 98.17%；第二輪依批次大小把學習率降為 1e-4 後為 98.72%（較保守的 5e-5 為 98.74%，差距在誤差範圍內），與 1.5B 相當，推論時間卻多一倍。

> TABLE 表 6-2　Qwen2.5 各種用法的測試 AUC（%）
| 模型 | 零樣本 | 8 則範例 | LoRA 微調 |
|:---|:---:|:---:|:---:|
| Qwen2.5-0.5B | 95.21 | 95.64 | 98.32 ± 0.05 |
| Qwen2.5-1.5B | 97.01 | 97.19 | 98.70 ± 0.03 |
| Qwen2.5-3B | 96.86 | 97.25 | **98.72 ± 0.02** |
> NOTE 註：LoRA 使用全部 30,464 筆訓練資料，為 3 個種子的平均 ± 標準差；Qwen2.5-3B 為第二輪學習率 1e-4 的結果（第一次學習率 2e-4 為 98.17%）。參照：BERTimbau Large 微調為 98.60% ± 0.08%。

## 6.3　跨資料集泛化

在五個資料集上各自訓練 BERTimbau Base，再直接套用到其他資料集的測試集。**電商之間轉移得很好**：在 Olist 訓練的模型套用到 B2W 為 98.64%。**電影評論最難轉移**：套用到電影評論會掉 8–15 個百分點（Olist → 電影 83.45%），TF-IDF 掉得更多（65.5%）。**零樣本 LLM 與領域無關**：Qwen2.5-1.5B 不使用任何訓練資料，在電影評論（90.78%）與 Buscapé（93.86%）上都勝過所有在其他資料集訓練的 BERT（最佳分別為 86.61% 與 92.53%）。因此，**新平台完全沒有標註資料時，零樣本 LLM 比「拿別的網站訓練的模型直接套用」更安全**。

## 6.5　小結

RQ2 的答案是：**資料量與成本會改變「哪個方法最好」**。資料越少，預訓練模型越重要；以 LoRA 微調的 LLM 最準，但成本也最高；零樣本 LLM 準確度較低，卻在沒有標註資料或跨領域時最穩健。
