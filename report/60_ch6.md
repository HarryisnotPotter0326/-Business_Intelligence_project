# 第六章　RQ2 延伸：資料量與大型語言模型

## 6.1　學習曲線

表 6-1 與圖 6-1 為不同訓練資料量下各方法的測試 AUC。有三個主要發現：

（1）**資料越少，預訓練模型的優勢越大**。只有 1,000 筆訓練資料時，BERTimbau Large 凍結比 TF-IDF 高 1.78 個百分點；到全部 30,464 筆時只高 0.85 個百分點。TF-IDF 從 1,000 筆到 30,464 筆提升了 1.78 個百分點，凍結的 BERTimbau Large 只提升 0.85 個百分點，因為預訓練已經提供了大部分的語言知識。

（2）**微調在資料夠多時才拉開差距**。1,000 筆時，BERTimbau Base 微調（97.35%）與 Large 凍結（97.42%）相當；5,000 筆以上，Base 微調才穩定勝出。而 Base 微調只用 5,000 筆（97.99%），就勝過 TF-IDF 用全部 30,464 筆（97.42%），資料效率約為 6 倍。

（3）**LLM 的資料效率最高**。Qwen2.5-1.5B 以 LoRA 微調時，1,000 筆就達到 98.08%，與 BERTimbau Base 微調用 5,000–10,000 筆的水準相當；用全部資料時達到 98.70%，是所有方法中最高。Qwen2.5-3B 沒有比 1.5B 好（全部資料 98.17%），原因在 6.2 節討論。

## 6.2　大型語言模型：零樣本、少樣本與 LoRA

表 6-2 比較三種規模的 Qwen2.5 在四種用法下的表現。

**零樣本提示**完全不需要訓練資料。1.5B 模型的 AUC 為 97.01%，接近 TF-IDF 用 3 萬筆訓練的 97.38%，但仍低於所有 BERTimbau 方法；0.5B 只有 95.21%。值得注意的是，**模型越大，零樣本表現不一定越好**：3B（96.86%）略低於 1.5B（97.01%）。

**少樣本提示**的幫助很小：在提示中加入 4 或 8 則範例，AUC 只提高 0.1–0.5 個百分點，但提示變長使推論時間變成原本的 6–60 倍（3B 加 8 則範例時，每 1,000 則需要 647 秒）。

**LoRA 微調**才能讓 LLM 追上 BERT。1.5B 模型的 AUC 為 98.70% ± 0.03%，與 BERTimbau Large 微調的 98.60% ± 0.08% 相當（圖 5-1 的信賴區間重疊），準確率與負評 F1 也幾乎相同。0.5B 模型 98.32%，略低於 BERTimbau Base 微調。3B 模型（98.17%）反而比 1.5B 差，這應是設定問題而非模型能力：受限於 11 GB 顯示卡記憶體，3B 的批次大小只能用 8，卻沿用 1.5B 的學習率 2e-4，最後的訓練損失為 0.184，明顯高於 1.5B 的 0.125–0.134，顯示訓練不夠穩定。由於只有 1 個種子且沒有另外調整超參數，3B 的結果不能解讀為「模型越大越差」。

## 6.3　判斷門檻校正

表 6-2 的「判為正面」欄顯示，所有提示式用法都把太多評論判成負面（判為正面只有 57%–64%，實際為 70%），以固定門檻 0 分類時準確率因此偏低。這與 Zhao et al. (2021) 指出的標籤偏誤一致。圖 6-2(b) 顯示，只要在驗證集上調整門檻，AUC 不變，但準確率可提高 0.9–4.0 個百分點：例如 3B 零樣本從 90.7% 提高到 93.3%，3B 加 8 則範例從 91.6% 提高到 94.1%。以「判為正面的比例對齊訓練集」決定門檻的效果相近（附錄表 A-4）。實務上，**零樣本 LLM 在上線前一定要用少量標註資料校正門檻**。

## 6.4　跨資料集泛化

表 6-3 為 BERTimbau Base 在五個資料集兩兩互測的結果（TF-IDF 的結果見附錄表 A-5），圖 6-3 以熱力圖呈現。主要發現如下：

（1）**電商之間轉移得很好**。在 Olist 訓練的模型套用到 B2W，AUC 為 98.64%，甚至高於 Olist 自己的 98.37%；在 B2W 訓練的模型套用到 Olist 為 97.41%，比 Olist 自己訓練只低約 1 個百分點。

（2）**電影評論最難轉移**。不論在哪個資料集訓練，套用到電影評論都會掉 8–15 個百分點（例如 Olist → 電影 83.45%）；反過來，在電影評論訓練的模型套用到其他資料集也最差。電影評論較長、常描述劇情，情緒表達方式與商品評論不同。

（3）**TF-IDF 轉移得更差**。TF-IDF 從 Olist 轉到電影評論只有 65.5%（BERT 為 83.5%），預訓練的語言知識讓 BERT 對領域變化更穩健。

（4）**零樣本 LLM 與領域無關**。Qwen2.5-1.5B 不使用任何訓練資料，在電影評論（90.78%）與 Buscapé（93.86%）上，勝過所有在其他資料集訓練的 BERT（最佳分別為 86.61% 與 92.53%）。因此，**當目標領域完全沒有標註資料時，零樣本 LLM 比「拿別的網站訓練的模型直接套用」更安全**。

原論文表 3 的跨資料集結果（例如 Olist → 電影 93.2%）明顯高於本研究。如 5.3.2 節所述，原論文的跨資料集比較使用「微調後的向量＋邏輯斯迴歸」，邏輯斯迴歸可能使用了目標資料集的資料訓練；本研究則是完全不使用目標資料的直接套用，因此兩者不能直接比較，本研究的設計較接近「新平台沒有任何標註資料」的實務情境。

## 6.5　準確度與成本的取捨

表 6-4 為各方法的推論速度與顯示卡記憶體，圖 6-4 把準確度與推論時間放在同一張圖上，虛線為「效率前緣」：在相同或更少的推論時間下，沒有其他方法比前緣上的方法更準。前緣上依序只有四個方法：TF-IDF、BERTimbau Base 微調、BERTimbau Large 微調與 Qwen2.5-1.5B LoRA。

- **TF-IDF** 每 1,000 則只要 0.018 秒（CPU），AUC 97.38%，是成本極低時的最佳選擇。
- **BERTimbau Base 微調**每 1,000 則 0.29 秒，AUC 98.43%；比最佳的 Qwen-1.5B LoRA 只低 0.27 個百分點，推論時間卻只有其 1/26，訓練時間也只要 1.2 分鐘（LoRA 約 20 分鐘）。
- **BERTimbau Large 微調**多花約 3 倍時間，換來 0.17 個百分點。
- **Qwen-1.5B LoRA** 最準，但推論時間是 Base 的 26 倍、需要 3.5 GB 顯示卡記憶體。

Olist 每天約產生 100 則評論，所有方法都能即時處理；但若要處理整個平台的大量評論，或是部署在沒有 GPU 的環境，BERT 的成本優勢就很重要。

## 6.6　小結與選型建議

RQ2 的答案是：**資料量與成本會改變「哪個方法最好」的答案**。資料越少，預訓練模型的優勢越大；LLM 以 LoRA 微調後可以達到最高的準確度，但成本也最高；零樣本 LLM 準確度較低且需要校正門檻，卻在沒有標註資料或跨領域時最穩健。表 6-5 整理不同情境下的建議。

> TABLE 表 6-5　不同情境下的情感分類方法選擇
| 情境 | 建議方法 | 理由 |
|:---|:---|:---|
| 有數千筆以上標註資料、需要大量即時推論 | BERTimbau Base 微調 | 準確度接近最佳，推論成本只有 LLM 的 1/26 |
| 追求最高準確度、運算資源充足 | BERTimbau Large 微調或 Qwen-1.5B LoRA | 兩者相當（98.6%–98.7%）；集成幫助有限 |
| 只有約 1,000 筆標註資料 | Qwen-1.5B LoRA 或 BERTimbau Large 凍結 | 資料少時預訓練知識最重要 |
| 完全沒有標註資料（新平台、新領域） | Qwen-1.5B 零樣本＋少量資料校正門檻 | 與領域無關，跨領域比轉移的 BERT 穩健 |
| 沒有 GPU、成本極低 | TF-IDF＋邏輯斯迴歸 | 97.4%，每千則 0.02 秒 |
