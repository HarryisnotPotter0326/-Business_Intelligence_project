#! AI 工具使用聲明

本研究依課程規定，說明 AI 工具的使用方式與範圍。

**使用的工具**：Anthropic 的 Claude Code (Anthropic, 2026)，在作者本機的 VS Code 中執行。

**AI 工具協助的工作**：

- 撰寫與除錯 Python 程式，包括資料處理、模型訓練、統計檢定與繪圖程式。
- 設計自動化的批次實驗流程，讓每段實驗完成後自動記錄結果與更新摘要。
- 整理實驗結果、繪製圖表，並撰寫報告初稿。
- 第五章 120 則錯誤樣本的原因歸類：由 AI 依預先定義的準則初分並寫出理由。
- 協助閱讀原論文，例如讀取圖 1 的數值、整理參考文獻。

**作者負責的工作**：

- 決定研究題目、研究問題與實驗範圍。
- 在本機（RTX 2080 Ti）親自執行所有實驗，並檢查每一段的輸出與記錄。
- 檢查實驗結果是否合理，複核錯誤樣本的歸類。
- 審閱並定稿報告的所有內容，對報告的正確性負責。

**AI 協助發現並修正的問題**：實驗過程中，AI 工具在檢查結果時發現了三個問題並協助修正：（1）BERT 微調第 1 個 epoch 沒有啟用 dropout（5.5 節），修正後重跑全部微調實驗；（2）RQ4 時點 B 原本使用的「交給物流天數」含有未來資訊（3.6.1 節），改為在當下即可確認的旗標；（3）交叉評分時顯示卡記憶體未正確釋放，只影響執行速度，不影響結果。所有修正前後的結果都保留在專案中以供查核。

本報告的所有實驗數字都來自實際執行的程式輸出，不是由 AI 生成的；程式、原始結果與執行記錄都保留在專案資料夾中（程式清單見附錄表 A-8）。
